# 📝 React Todo App

A simple and clean Todo application built with React.  
You can add tasks, edit them, and delete them — perfect for practicing CRUD operations and learning React basics.

---

## 🚀 Features

- ➕ Add new tasks  
- ✏️ Edit existing tasks  
- ❌ Delete tasks  
- 💾 Tasks saved in state  
- 📱 Fully responsive UI  
- ⚡ Built using modern React hooks (`useState`)

- **CSS module
